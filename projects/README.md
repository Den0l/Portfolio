# Добавление проектов

Создайте в `projects/` по папке для каждого проекта и положите в неё
изображения:

```text
projects/
  Outfits/
    look-01.jpg
    look-02.png
  Studio/
    campaign/
      photo-01.webp
      photo-02.jpg
```

Название папки становится названием карточки. Дефисы и подчёркивания
преобразуются в пробелы, слова начинаются с заглавной буквы. Изображения из
вложенных каталогов также попадут в проект; скрытые файлы и папки
игнорируются.

Поддерживаемые форматы: `.avif`, `.gif`, `.jpeg`, `.jpg`, `.png` и `.webp`.
Фотографии сортируются по пути в естественном алфавитном порядке: например,
`look-2` раньше `look-10`. Слайдер показывает фотографии из всех проектов.

После добавления или изменения изображений запустите `npm run build` из
корневой папки проекта. Публикуется сгенерированный каталог `dist/`; не
редактируйте его напрямую.
